## LC-002 Maximum Thrust

Physical Meaning:
The condition where the motor produces maximum continuous static thrust.
This load represents the primary axial load in the motor mount design.

Applied Force:
T = 28.77 N

Motor Weight:
W = 0.592524 N

Resulting Load on Mount:
R = 28.18 N

Factor of Safety
FoS = 2

Design Load:
R = 56,36 N
